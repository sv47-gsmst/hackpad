
## <ins> Overview </ins>


I built a custom 6-key macropad with a rotary knob, designing the electronics, PCB, and case myself. The entire project took about 8 hours to finish, from the schematic to the case

## Goal:

I wanted to create a compact mini keyboard that can help me with shortcuts and quick commands such as arrow keys. 


## Build Process:

This project involved wiring a schematic and PCB around a Seeeduino-XIAO microcontroller. As well as building a case for my PCB, and writing firmware for the macropad. Throughout this project I had many challenges in routing the wires in the schematic to the microcontroller, getting the right measuements and extruding the case properly, as well as checking to see if the PCB size and case size both fit perrfectly. In the end the final product had a Schematic and PCB design, KMK firmware for the macropad, finished with a custom case.



### <ins> Bill of Materials </ins>

- 6x Sw_Push

+ 6x 1N4148 Diodes

* 1x RotaryEncoder_Switch

- 1x Seeeduino XIAO

### <ins> Software: </ins> 

- Kicad 10.0 for Schematic

+ Kicad 10.0 PCB design

* KMK firmware

- Autodesk Fusion 360 for CAD
